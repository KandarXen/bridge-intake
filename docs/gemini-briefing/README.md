# Gemini marketing briefing package

Send Gemini these files together:

1. `BTAI_GEMINI_MARKETING_BRIEF_v1.md`
2. The current public page screenshot or HTML
3. The current intake/snapshot screenshot or HTML
4. A redacted free-report sample, if available
5. The Gemini prompt supplied by Codex

This package authorizes Gemini to recommend positioning, copy, layout, and a
standalone HTML concept. It does not authorize deployment, changes to the
intake product, claims beyond the brief, or disclosure of proprietary methods.
