# BTAI Intake v1.72.25 — Private Preview Sign-off

## Purpose

v1.72.25 improves private-tester readiness without changing the public production site.

## What is included

- Clearer v1.72.25 Preview label in the tester interface.
- A more legible five-signal scorecard graphic.
- Visible saved-draft and restored-draft confirmations.
- A safety-contract test that checks AI/report feature switches and draft capability boundaries.
- Free-report continuation links use the configured private base URL when report delivery is approved later.
- AI prompts are privacy-gated directly; a separate browser-supplied scan summary cannot bypass the prompt scan.
- Preview report delivery requires an explicit recipient allowlist and has no default BCC recipient.

## Private Preview operating state

- AI generation: enabled only for the approved private Preview branch.
- Client report email delivery: disabled until separately approved.
- Completion notification email: disabled until separately approved.
- Public production deployment: not authorized.
- Live AI calls for release verification: not run; contract tests use no external AI service.

## Required checks

Run from the repository root:

```powershell
node scripts/pilot-safety-contract-test.mjs
node scripts/privacy-gate-context-test.mjs
```

Expected result from each command: a passing message and exit code `0`.

## Manual tester checks

1. Enter synthetic details and wait for **Your answers are saved. It is safe to refresh this page.**
2. Refresh and confirm **Your saved answers were restored. You can keep going.**
3. Attempt to load a saved draft using only its record ID and no capability: expect `403`.
4. Confirm the scorecard graphic is readable and the five detailed signals are listed only once.
5. Only invited testers using synthetic information may submit a completed intake and trigger AI generation.

## Release boundary

Do not enable `BTAI_ENABLE_CLIENT_REPORT_PACK` or promote this branch to Production without the owner's explicit approval.
Do not enable `BTAI_ENABLE_COMPLETION_NOTIFICATIONS` without the owner's explicit approval.
Before enabling Preview report delivery, configure `BTAI_PREVIEW_REPORT_RECIPIENTS` with the approved tester email addresses and set `BTAI_PUBLIC_BASE_URL` to the intended private Preview host. Preview report delivery fails closed if that base URL is absent.
